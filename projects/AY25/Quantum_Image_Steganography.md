# Quantum Image Steganography

**Repo link** [Click here](https://github.com/JuzerL/Quantum-Image-Steganography-using-NEQR-and-Multi-LSB-Embedding)

A framework on Quantum Image Steganography based on the Novel Enhanced Quantum Representation (NEQR), implemented using Qiskit. The system consists quantum image encoding using NEQR, LSB secret data embedding, and measurement based extraction of the hidden information.

## Key Principles

* **NEQR Image Encoding:** Represents pixel intensities directly in quantum basis states.
* **Quantum Image Seganography:** Embeds secret image data within the quantum encoded pixels, encoded using NEQR.
*  **LSB embedding:** Flips the Least Significant Bit(s) of a quantum register representing a pixel.
*  **Quantum State Manipulation:** Uses controlled quantum operations to encode and modify pixel data.
*  **Quantum Parallelism:** Processes all pixel positions simultaneuosly using superposition.

## Features

* Complete NEQR-based quantum image steganography pipeline.
* LSB-based secret embedding within quantum intensity register
* Measurement-driven extraction with deterministic recovery
* Qiskit-based simulation of full encoding and decoding process
